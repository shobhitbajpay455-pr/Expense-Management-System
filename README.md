# Expense Management System

## About
This is a Python-based Expense Management System developed as a Capstone Project.

## Features
- Add expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Store expense data in CSV format

## Technologies Used
- Python
- CSV
- Git
- GitHub

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run `expense.py`.
4. Follow the menu options shown in the terminal.

## Project File
- `expense.py` - Main Python program
